## Context

Gresik Regency needed its application security practices written down in a form auditable
against **BSSN Regulation No. 4/2021**, covering both the mobile and web applications the
regency operates.

## What I did

- Authored **7 SOPs for mobile applications**, covering authentication, session management,
  resilience, cryptography, and related controls
- Authored **13 SOPs for web applications**, covering business logic security, API security,
  access control, and related controls
- Produced a **data flow chart for every SOP**, so each control is traceable to the data path it
  protects

## Outcome

Twenty controls moved from implicit practice to documented, chartable procedure, giving the
regency's application teams a security baseline that survives staff turnover.
