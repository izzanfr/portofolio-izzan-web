## Context

Magelang City's SPBE documentation required reference coding at scale. Every service, data
entity, and application across the city government had to be identified against the national
reference architecture, then read against where the city wants to be.

## What I did

- Analyzed **30+ regional agencies (OPD)**
- Produced **200+ service architecture reference codes**
- Produced **700+ data architecture reference codes**
- Produced **500+ application architecture reference codes**
- Performed the **as-is to to-be analysis** connecting current state to the city's digital
  transformation vision

## Outcome

More than 1,400 coded architecture elements gave Magelang a machine-readable baseline. The gap
between as-is and to-be became a list of specific codes rather than a narrative.
